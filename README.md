# Morpion en Python

Jeu du Morpion (Tic-Tac-Toe) à deux joueurs, à jouer dans le terminal.

## Fonctionnalités
- Plateau de 3x3 affiché dans le terminal
- Deux joueurs (❌ et ⭕) qui jouent chacun leur tour
- Détection des victoires (lignes, colonnes, diagonales) et des matchs nuls
- Validation des saisies (case déjà prise, nombre hors limites, valeur invalide)

## Lancer le jeu
Il faut Python 3 installé.

    python morpion.py

Les cases sont numérotées de 1 à 9, de gauche à droite et de haut en bas.
